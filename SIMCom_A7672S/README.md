# SIMCom A7672S Master Scripts

1. **SIMCOM_A7672S_MASTER(4G).py** An advanced telemetry and control script optimized for standard Physical SIM deployments on the PiHAT A7672S. It features a user-selectable communication interface for seamless switching between hardware UART (for lightweight testing) and the high-speed USB Type-C interface (for primary MQTT payload delivery). Engineered for maximum field uptime, it includes bulletproof auto-recovery logic, absolute attempt-counters for baseband lockups, hardware-level auto-reboot sequences, dynamic APN toggling, and automated DS3231 Real-Time Clock (RTC) setup to guarantee all payloads are stamped with precise hardware time prior to transmission.

2. **SIMCOM_A7672S_MASTER(4G+GNSS).py** An extended framework specifically tailored for the A7672S-FASE (GNSS-enabled) hardware variant. Building upon the robust 4G network foundation, this script leverages the module's dedicated onboard GNSS silicon. It actively manages the active antenna power rails (via CVAUXS) and forces simultaneous LTE/GNSS execution modes to prevent RF de-sense, seamlessly injecting high-precision satellite coordinates directly into the RTC-stamped MQTT payloads.

3. **SIMCOM_A7672S_MASTER(eSIM).py** A specialized production script engineered explicitly for embedded IoT deployments. It utilizes hardware-level logic to physically route the A7672S baseband processor directly to the onboard STMicro eSIM chip via GPIO multiplexing, completely bypassing the plastic SIM slot. It maintains all the bulletproof auto-recovery tripwires, strict AT command buffer management, and self-healing MQTT session rebuilding found in the primary physical SIM framework.
