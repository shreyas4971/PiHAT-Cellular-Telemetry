**1. QCTL_EC200_master.py** An all-in-one telemetry and control script tailored for the PiHAT EC200, combining network management, location tracking, and precise timekeeping into a single workflow. The script features a user-selectable communication interface, allowing seamless switching between high-speed USB Type-C (ideal for full 4G MQTT sessions and hardware-driven GNSS polling) and GPIO-based UART (for lightweight AT command testing without tying up USB ports). Additionally, it automatically initializes the onboard DS3231 Real-Time Clock (RTC) over the I2C bus, ensuring all generated telemetry payloads maintain accurate, localized timestamping even during complete network outages.
